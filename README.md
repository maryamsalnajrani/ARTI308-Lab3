# ARTI308 - Lab 3

## Dataset Description
The Telco Customer Churn dataset contains information about customers of a telecommunications company, including their services, account information, and whether they have left the company.

## Machine Learning Problem
The goal is to predict whether a customer will churn or not based on the available customer information. This is a classification problem because the target variable, `Churn`, has two possible classes: Yes or No.

**Target Variable:** Churn  
**Problem Type:** Classification
